Xpired for GFOS
===============

X-pired, the Sokoban-like action puzzle by Miroslav Kucera and friends (bombs, crates, fire, ice and teleports), for GFOS (AmigaOS 3.2 with GFOpenUp) on a 68040 with GFOpenUp's SDL 2.

The port is being written on branch team3/xpired-port-20261116.

Designed, tested and delivered by The AmiCradle Team.
